A full-stack event management platform built with React, Spring Boot, KeyCloak, Adminer and PostgreSQL that digitizes the complete event ticketing and check-in process.

Users can discover events, book tickets, and receive unique QR-code-based tickets. Event staff can scan the QR codes at the venue and instantly validate tickets, ensuring secure and efficient attendee check-in while preventing duplicate entries.
